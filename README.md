## About This Repository

This repository serves as my personal cybersecurity learning portfolio, documenting my progress through Hack The Box challenges and authorised penetration-testing labs.

Each writeup follows a structured methodology:

1. Machine Information
2. Introduction and Learning Objectives
3. Network Connectivity Testing
4. Network Enumeration
5. Service Investigation
6. Security Analysis
7. Security Recommendations
8. Key Learning Outcomes
9. Personal Reflection
10. Conclusion

My goal is not simply to complete challenges, but to understand the underlying security concepts, explain my technical findings clearly, and identify appropriate security improvements.
